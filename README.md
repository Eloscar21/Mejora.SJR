# Mejora SJR - Plataforma Ciudadana

Sistema integral para el reporte, seguimiento y gestión de incidencias en San Juan del Río.

---

## Estructura del Proyecto

* **`mejora-sjr-backend/`**: API RESTful construida con Node.js, Express y Azure SQL bajo una estricta arquitectura de N-Capas y principios SOLID.
* **`mejora-sjr-admin/`**: Dashboard Web para administradores y dependencias municipales.
* **`mejora-sjr-mobile/`**: Aplicación móvil para ciudadanos y trabajadores de campo.
